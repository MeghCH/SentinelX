# Collaborative coding convention
**The W00M00H00 (Woumouhou) convention**

Branches Naming Convention :
> Each task prent on the Trello Board **must** have it's own branch. Each branch name **must** comply with the Trello Task name.

- `feat/W01-task-name`
- `fix/M01-task-name`
- `docs/H01-task-name`

Commit Messages Convention :
> Each commit message **must** comply with the conventional commit message 

- `feat: feature description`
- `fix: fix description`
- `doc: documentation info`
- `wip: work in progress task`
- `refactor: explaination`

Pull Request convention :

- Each **Push** must absolutly be on your branch. Nothing on the `main` or `dev` branch directly
- A branch should never been merged without a Pull Request first
- Any branch (exept for the `dev` branch) can be merged on the `main` branch
